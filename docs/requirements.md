# Жүйеге қойылатын талаптар
## Функционалдық талаптар
1. Пайдаланушы жүйеге кіре алады.
2. Пайдаланушы ақпаратты қарай алады.
3. Пайдаланушы ақпаратты өзгерте алады.
4. Әкімші жүйені басқара алады.
## Функционалдық емес талаптар
1. Жүйе ыңғайлы болуы керек.
2. Жүйе жылдам жұмыс істеуі керек.
3. Деректер қауіпсіз сақталуы керек.
